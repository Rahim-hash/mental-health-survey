# AI Usage

AI was used for planning, idea development, and research, as follows:

- Helping narrow the topic and brainstorm coherent, non-duplicated survey questions
- Suggesting a mix of form element types (dropdown, radio, checkboxes, textarea, range,
  Likert table) to cover the assignment requirements
- Reviewing the HTML, CSS, and JavaScript against the assignment specification and marking
  criteria
- Identifying and fixing a bug where user input was not escaped before being displayed in
  the results section, which could break the HTML output

All final code was written, tested, and refined by the student.
